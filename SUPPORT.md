# Support

LibreStaff is a community-maintained open-source project and does not include guaranteed support or
response times.

## Where to Ask

- Ask installation, configuration, deployment, and usage questions in
  [GitHub Discussions](https://github.com/moh92ahm/librestaff/discussions).
- Use a GitHub issue for a reproducible bug or an accepted, actionable feature proposal.
- Report security vulnerabilities privately according to [SECURITY.md](SECURITY.md).

Before asking, search the README, existing discussions, and issues. Include the LibreStaff version,
deployment method, relevant sanitized configuration, expected behavior, and what you already tried.

## Protect Sensitive Data

Never post secrets, `.env` contents, database dumps, authentication cookies, private logs, CVs,
payroll information, or identifiable employee/applicant data. Redact domains and infrastructure
details when they are not necessary to reproduce the problem.

## Project Scope

Community support covers LibreStaff itself. Maintainers may be unable to troubleshoot custom forks,
third-party infrastructure, private integrations, or unsupported changes.

## Professional Services

Organizations that need tailored production deployment, data migration, customization, upgrades,
monitoring, backup and restore planning, or ongoing maintenance can request commercial assistance
from the project maintainer:

[LibreStaff professional services](https://yourwebsite.com/librestaff)

Commercial enquiries should use that contact route rather than GitHub issues or security reports.
Availability, scope, pricing, response times, and service terms are agreed separately. Purchasing a
service is optional and does not change LibreStaff's AGPL-3.0-only license or the ability to
self-host it.
